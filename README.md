# Europe-Crime-Analysis
Analysis of Eurostat crime data (2014–2023) exploring the impact of population size, trends over time, and risk-based country profiling.

---

## 📂 Data Source

- Eurostat Crime Statistics (2014–2023)  
- 27 EU countries  

---

## ⚙️ Methodology

- Cleaned and standardised crime data across countries  
- Calculated per capita crime rates  
- Analysed trends over time  
- Grouped countries into profiles based on:
  - Risk per person  
  - Trend direction (increasing/decreasing)  

---

## 📈 Outputs

The project includes:
- Ranking comparison charts (raw vs per capita)  
- Trend analysis visualisations  
- Country risk profiling scatter plots  
- Final presentation summarising findings  

---

## 🔁 Reproducibility

To reproduce this analysis:

1. Download or clone this repository  
2. Install required Python packages  
3. Run the scripts in the `scripts/` folder  
4. Outputs will be generated in the `outputs/` folder
